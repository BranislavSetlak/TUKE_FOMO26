# TUKE_FOMO26

The TUKE hybrid sequence-pretraining experiment is documented in
[`slurm/tuke_hybrid/README.md`](slurm/tuke_hybrid/README.md). It combines 3D
SwinUNETR masked reconstruction with class-balanced MRI-sequence
classification and is launched entirely through Slurm.

See [`TUKE_HYBRID_HANDOFF.md`](TUKE_HYBRID_HANDOFF.md) for the verified
starting point, implementation details, and launch commands.
